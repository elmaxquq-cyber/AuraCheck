# AuraCheck

Prototipo web para administrar productos, inventario, ventas y reportes.

## Cómo abrirlo

1. Descomprimí la carpeta del proyecto.
2. Abrí `prototipoweb` desde Visual Studio Code.
3. Abrí `index.html` en el navegador (se recomienda la extensión Live Server).
4. Creá una cuenta desde **Crear cuenta** y luego iniciá sesión.

## Pantallas

- `index.html`: inicio de sesión.
- `crear-cuenta.html`: registro de usuarios.
- `principal.html`: panel principal y navegación.
- `agregar.html`: alta y eliminación de productos.
- `inventario.html`: consulta de stock.
- `registrar.html`: registro de ventas y descuento de stock.
- `historial-ventas.html`: historial de operaciones.
- `reportar.html`: formulario de reportes.

## Tecnologías

El prototipo actual usa HTML5, CSS3 y JavaScript ES6. Guarda información de demostración en `localStorage` del navegador. La arquitectura Cloud-Native propuesta para la versión conectada está en `documentos/stack-tecnologico.md`.

> Importante: esta versión es educativa. No utiliza un backend ni una base de datos real, y no debe usarse para almacenar información sensible.
